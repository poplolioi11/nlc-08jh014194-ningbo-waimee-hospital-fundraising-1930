# 寧波華美醫院徵信錄

《寧波華美醫院徵信錄》刊於 1930 年 3 月，記述浙江寧波華美醫院籌建沿革、建築及設備捐款、經募、決算與圖版。資料依中國國家圖書館 08jh014194／37817 底本轉錄，捐助人、金額、原刊空欄和疑讀皆可回到原圖。

A source-linked transcription of the March 1930 Ningbo Huamei Hospital fundraising accounts, relating to the new hospital, construction, equipment, donations and income and expenses.

- 原刊由華美醫院編纂，刊次 民國十九年三月（1930），浙江寧波。共 77 幅，依底本分幅定位。 [館藏／原件](https://commons.wikimedia.org/?curid=131010077)

- JSON 保留欄位及各幅來源雜湊。TXT 可連讀，TEI 可供交換與字位掛接。

- 全冊 AI 輔助初錄，77 幅均保留底本定位。表格依原刊輸入，照片只存圖說與位置。後加館藏記號另列，尚待人工逐字核對。
