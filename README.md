# 寧波華美醫院徵信錄

《寧波華美醫院徵信錄》記錄浙江寧波華美醫院籌建新院的經過，收錄建築與設備捐輸名單、圖版題記及收支總報。資料依中國國家圖書館 08jh014194／37817 藏本 77 幅影像逐幅定位，以 JSON、TXT 與 TEI XML 保留直欄讀序、原表空格、經募小字及金額。可供近代醫療慈善、募捐網絡和醫院發展史查閱。

The 1930 Ningbo Waimee Hospital report documents the fundraising and construction of a new hospital in Ningbo, Zhejiang. It includes donor registers for the building and equipment, photo inscriptions, and a financial statement. JSON, plain text and TEI XML cover the 77 scans of National Library of China copy 08jh014194/37817, with source coordinates for archival and philanthropic history.

- 原刊由華美醫院編纂，刊次 民國十九年三月（1930），浙江寧波。共 77 幅，依底本分幅定位。 [館藏／原件](https://commons.wikimedia.org/?curid=131010077)

- JSON 保留欄位及各幅來源雜湊。TXT 可連讀，TEI 可供交換與字位掛接。

- 已逐幅對讀兩份由 AI 依同一底本辨識的文字，並回原圖裁定歧讀。捐款名錄的未定字、雙行附註及原刊數字不一致處均保留。尚待人工全文校對。

- 歷史原刊為公有領域。新撰說明與編碼 [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/)。來源影像的權利與使用條件見原件頁。
